# Open source

Love Is My Heart is itself MIT-licensed and is assembled from open-source
projects. The app would not exist without them. This file records the main
building blocks, their licences and what they do here.

## Android app

| Project | Licence | Used for |
| --- | --- | --- |
| [AndroidX WebKit](https://developer.android.com/jetpack/androidx/releases/webkit) / `WebViewAssetLoader` | Apache-2.0 | Serving bundled demo assets from a same-origin `https://` origin |
| [AndroidX Core](https://developer.android.com/jetpack/androidx) | Apache-2.0 | Transitive AndroidX support |
| Android WebView / Chromium | BSD-style / Apache-2.0 | Rendering the demo and the self-hosted web app |

The Android shell no longer hand-rolls URL interception. `WebViewAssetLoader`
is the open-source AndroidX component that maps `/demo/...` to the APK's
`assets/demo/...`; a small path handler is kept only to set exact MIME types
for fonts and images on older WebView versions.

## Demo content

The eight demo portraits are generated sample images, not photographs of real
members. The profiles, prompts and replies are fictional and are labelled as
samples in the UI.

## Reporting

If you believe a credit is missing or a licence is stated incorrectly, open an
issue and it will be corrected. The full dependency tree and exact versions are
in `package-lock.json`, `android/app/build.gradle` and the Gradle lockfiles
generated by the build.
